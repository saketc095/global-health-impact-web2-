**Global Health Impact Project**


**Overview :-**

This repository contains work completed as part of the Termination Project for the Master’s in Computer Science at Binghamton University. The project was carried out under the Global Health Impact Project and focused on improving data driven tools and web applications that measure the impact of pharmaceutical products on global health.
The primary goal of the project was to automate data collection and analysis, improve the existing website, and implement a forecasting tool to evaluate the global health impact of medicines.


**Project Objective :-**

The objective of this project was to design and implement web based software applications and statistical models to support the Global Health Impact Index. The work involved improving website performance, modernizing the codebase, and building a forecasting tool to measure pharmaceutical product impact on global health outcomes.


**Brief Description :-**

The Global Health Impact Project aims to advance access to essential medicines, especially in resource poor settings. It provides data and tools that help inform policies for equitable access to medicines with the greatest impact on global health.
As part of this project, a forecasting tool was developed to measure the impact of pharmaceutical products on global health. In addition, the website was enhanced through better code structure, periodic updates, and migration to a newer Python version.
